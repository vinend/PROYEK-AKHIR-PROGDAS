

# ENERGETICA

**ENERGETICA** is an interactive game where players take on the role of a leader striving to optimize resources and achieve sustainable development goals (SDG 7: Affordable and Clean Energy) for various fictional cities. The game combines strategy, resource management, and sustainability education, making it both educational and engaging.

## Key Features

- **Resource Management**: Balance budgets, resources, and time to improve energy access, cleanliness, and sustainability.
- **Strategic Decisions**: Optimize various sectors like electricity, clean energy, household cleanliness, and greenhouse gas emissions.
- **Educational Content**: Learn about the challenges and trade-offs in achieving clean and sustainable energy solutions.
- **Engaging Gameplay**: Level-based challenges with descriptive city profiles and evolving scenarios.

## Technology Stack

- **Programming Language**: C
- **Libraries**: Standard C libraries for input/output, string manipulation, and memory management.
- **ANSI Color Codes**: Used to enhance the terminal-based user interface.

## Game Structure

1. **City Profiles**:
   - Each city has unique challenges in energy access, cleanliness, and emissions.
   - Players must balance improvements across multiple indices (electricity, cleanliness, clean energy access, and emissions).

2. **Resource Constraints**:
   - Budget, human resources, and time are limited for each city.
   - Strategic decision-making is required to maximize indices without exhausting resources.

3. **Interactive Options**:
   - Players can improve various sectors through specific actions:
     - Electricity Access: Improve subsidized electricity, public facility electricity, or renewable electricity.
     - Household Cleanliness: Manage sustainable tools, energy efficiency, and waste management.
     - Clean Energy: Enhance accessibility, cleanliness, or renewable energy adoption.
     - Emissions: Reduce CO2, CH4, or N2O emissions through targeted strategies.

4. **Winning Conditions**:
   - Achieve a composite city index above 75% while managing resources effectively.

## How to Play

1. **Compile the Code**:
   ```bash
   gcc ENERGETICA.c -o ENERGETICA
   ```

2. **Run the Game**:
   ```bash
   ./ENERGETICA
   ```

3. **Game Controls**:
   - Follow on-screen instructions to make decisions and improve city indices.
   - Use keyboard inputs to select options during gameplay.
